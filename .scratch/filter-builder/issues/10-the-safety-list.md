# The safety list: what is on it, where it lives, and what counts as failing

Type: grilling
Status: open
Blocked by: 03

## Question

A curated, player-extendable list of items that must never be silently lost, and
a standing panel showing each one's current verdict.

Decide what goes on the shipped list and by what standard, given that value is a
community judgement the game's tables do not hold. Decide how an entry is named -
a unique by file index, a rune by code, a base with sockets is not a source at
all - and where the list lives, given it is an opinion that will need updating
without a BH release.

Decide what counts as failing: hidden outright, unnamed, untiered, tiered below
the player's own notify threshold, or named so quietly it will be missed. Decide
which filter context an entry is checked under, since an item safe at one filter
level is not safe at another, and how the player adds their own entries.
